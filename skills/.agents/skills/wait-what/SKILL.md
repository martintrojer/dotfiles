Wait. Your last message didn't land — I stopped following it.

Re-pitch **that**: not necessarily the last paragraph, as far back as the
misunderstanding goes. Add the premise you skipped.

- **Re-explain, don't re-answer.** No new claims, no new questions answered,
  no tools. Only re-express what you already said.
- **Facts survive verbatim.** Every path, command, filename, number, URL, flag
  and decision stays character-identical. Simplify the prose around them.
- **Simpler, not shorter.** Take the space real clarity needs. Cut hedging and
  ceremony, not content. If the re-pitch is terser and still opaque, you failed.
- **Flatten it.** Drop headers and tables; plain sentences.
- **Project nouns, not invented ones.** Use the vocabulary from this repo's
  `AGENTS.md` and package docs. If you coined a term, name what it maps to.
- Twice in a row must keep working. No degrading into telegrams.

If there is no previous message of yours to re-pitch, say so.
